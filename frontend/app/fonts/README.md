# Pretendard

Unmodified Pretendard Variable 1.3.9 from the official project:
https://github.com/orioncactus/pretendard/tree/v1.3.9/packages/pretendard/dist/web/variable/woff2

Distributed under SIL Open Font License 1.1; see ../../public/licenses/Pretendard-LICENSE.txt (also served at /licenses/Pretendard-LICENSE.txt).
The complete Korean/Latin variable font is served locally through next/font/local.
It uses font-display: swap and is not preloaded, so it does not compete with
critical page assets. Code and logs retain the existing monospace font.
